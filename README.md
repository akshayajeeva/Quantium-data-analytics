# Quantium-data-analytics
Data analysis project on retail transactions to identify customer behavior and evaluate store performance using Python.
# Quantium Data Analytics Job Simulation

## 📊 Project Overview
This project is based on the Quantium Data Analytics Virtual Experience Program on Forage. The objective was to analyze retail transaction data and provide business insights.

---

## 🎯 Objectives
- Understand customer purchasing behavior
- Identify key customer segments
- Evaluate trial store performance
- Provide business recommendations

---

## ⚙️ Steps Performed

### 1. Data Cleaning
- Removed missing values
- Converted date formats
- Handled outliers

### 2. Exploratory Data Analysis
- Analyzed transaction trends
- Identified top-selling products
- Studied customer segments

### 3. Trial vs Control Analysis
- Compared store performance
- Measured impact of changes

### 4. Visualization
- Bar charts
- Line plots
- Customer segmentation graphs

---

## 📈 Key Insights
- Identified high-value customer segments
- Observed sales trends across stores
- Found differences between trial and control stores

---

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib / Seaborn
- Google Colab

---

## 🚀 Conclusion
This project demonstrates how data analytics can be used to generate business insights and support decision-making.
